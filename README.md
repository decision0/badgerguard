# BadgerGuard

BadgerGuard is an open-source Zero-Trust MFA Router and policy gateway.

- Acts as a reverse proxy in front of internal and SaaS apps
- Enforces MFA (WebAuthn, TOTP, push)
- Evaluates conditional access policies (device posture, IP reputation, geo, time-of-day)
- Integrates with Google Workspace, JumpCloud, Okta, and Active Directory

Work in progress.
