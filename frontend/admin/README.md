# BadgerGuard Admin UI

The BadgerGuard Admin UI is a React + TypeScript web application for managing tenants, applications, policies, users, and viewing audit logs.

## Features

- Tenant and application configuration
- Policy editor for OPA/Rego templates
- User and device management
- Audit log viewer with filtering
- Identity provider configuration

## Development

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
```

## Production

The built files can be served by the gateway or a separate web server.
