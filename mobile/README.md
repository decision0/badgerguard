# BadgerGuard Mobile Apps

React Native mobile applications for iOS and Android that provide push MFA approvals and TOTP token management.

## Features

- Push notification MFA challenges
- Approve/deny access requests
- TOTP token management
- Device binding and registration
- Secure storage using Keychain/Keystore

## Development

### Prerequisites

- Node.js 18+
- React Native CLI
- Xcode (for iOS)
- Android Studio (for Android)

### Setup

```bash
npm install
cd ios && pod install && cd ..
```

### Running

```bash
# iOS
npm run ios

# Android
npm run android
```
